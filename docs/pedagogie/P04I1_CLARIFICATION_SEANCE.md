# P0.4I.1 — Clarification de l’écran séance complète

## Problème

L’écran P0.4I mélangeait visuellement trois niveaux :

```text
objectif de séance
objectifs nourris
savoir-faire observés
```

Dans certains cas, le même intitulé apparaissait dans les trois blocs, ce qui donnait l’impression que tout était doublonné.

## Correction

### 1. Bloc 1 renommé

```text
Objectif de séance
→ Intention de séance
```

Ce bloc répond à :

```text
Pourquoi cette séance existe aujourd’hui ?
```

### 2. Bloc 2 renommé

```text
Objectifs nourris
→ Objectifs de projet alimentés
```

Ce bloc devient clairement optionnel et sert surtout aux bilans.

### 3. Bloc 3 renommé

```text
Savoir-faire observés
→ Savoir-faire à observer chez les participants
```

Ce bloc devient le cœur de l’évaluation individuelle.

### 4. Logique corrigée

L’objectif propre à la séance n’est plus automatiquement relié aux savoir-faire observés.

Les objectifs de séance ne remontent plus dans la liste des “objectifs de projet alimentés”.

## Règle fonctionnelle

```text
Intention de séance = pourquoi on fait la séance.
Savoir-faire observés = ce qu’on évalue individuellement.
Objectifs de projet alimentés = à quoi ça contribue dans le bilan.
Observations individuelles = données qui alimentent Evaluation et le passeport.
```
